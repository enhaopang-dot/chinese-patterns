## 这是什么

一套中国传统纹样的**知识与素材工具包**，三部分：

- **知识库**：纹样的寓意、分类、考据、视觉特征
- **矢量素材**：78 个可商用的纹样文件（回纹、云纹、寿字、福字、角点等）
- **两条生产线**：矢量转换、AI 生图辅助

## 核心原则

纹样知识分两档：

- **常识档**：大家都知道大概意思，可以随口说
- **考据档**：有出处、有版本、有区域差异，对外交付一律用这一档

素材优先自产，不裸用别人标了 CC 的图——那些常常带着署名要求或商用限制。

## 什么时候用它

- 做海报、书籍封面、品牌视觉，需要国风纹样
- 提到具体纹样名（莲花纹、卷草纹、宝相花、缠枝莲……）想知道它的来历和寓意
- 要把纹样用于生图提示词，需要准确的视觉描述
- 复刻「纹样图鉴」类的内容产品

## 常见的坑

1. **寓意会被以讹传讹**。同一个纹样在不同朝代、不同地域意思不一样，别一口咬定。
2. **CC 图不等于可商用**。署名、非商业、相同方式共享这些条件经常被忽略。
3. **AI 生成的纹样结构会错**。回纹的连续、缠枝莲的缠绕逻辑，AI 常画出断头。要么用矢量素材，要么人工校。
